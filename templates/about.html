PROJECT DOCUMENTATION

Algorithms behind the journey.

A working educational prototype showing how core Data Structures and Algorithms organize baggage workflows.

PROBLEM STATEMENT

How can baggage records be managed efficiently?

This project models registering baggage, prioritizing time-sensitive items, searching records quickly and sorting records by weight. The algorithms are implemented in Python and the records are stored in SQLite.

⇄   Queue

FIFO processing: first item added is first removed.

enqueue · dequeue
↑   Priority queue

Urgent baggage is selected before Priority and Normal baggage.

priority ordering
↕   Sorting

Bubble Sort, Insertion Sort and Merge Sort organize records.

O(n²) / O(n log n)
⌕   Searching

Linear Search scans records; Binary Search locates a sorted numeric ID.

O(n) / O(log n)
Scope: This is a simulated educational prototype, not connected to real airport systems or conveyor hardware. The application logic is Python; HTML and CSS create the interface. No JavaScript or React is used.
